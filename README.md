# student-result-analysis
=======
The Student Result Analysis System is a full-stack web application designed to streamline academic result management and performance analysis in educational institutions. The system provides separate dashboards for administrators and students with secure role-based authentication.

Administrators can manage student records, upload semester results, update marks, and monitor overall academic performance. The application automatically calculates Semester Grade Point Average (SGPA) and Cumulative Grade Point Average (CGPA) based on students' grades and credits, reducing manual effort and ensuring accuracy.

Students can securely log in to view their semester-wise results, subject-wise grades, SGPA, CGPA, and academic progress. The system also offers visual reports and performance analytics that help students track their improvement over time.

Built using modern web technologies, the application features a responsive user interface, efficient data management, and automated result processing. The project aims to improve transparency, accuracy, and efficiency in academic result management while providing meaningful insights into student performance.
